Each VPA component exposes Prometheus metrics on the address configured by its `--address` flag.

The tables below are generated from the registered VPA metric definitions, including shared metric helpers. Descriptions come from the Prometheus `Help` fields. Metrics provided by dependencies, such as Go runtime and client-go metrics, are not included.
Run `bash hack/update-metrics.sh` from the VPA directory after changing metric definitions. Verify the tables with `bash hack/verify-metrics.sh`.
