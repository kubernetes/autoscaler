The VPA Recommender exposes Prometheus metrics on the address configured by its `--address` flag. All Recommender metric names are prefixed with `vpa_recommender_`.

The table below is generated from the registered Recommender metric definitions, including shared metric helpers. Descriptions come from the Prometheus `Help` fields.
Run `bash hack/update-recommender-metrics.sh` from the VPA directory after changing metric definitions. CI checks the table with `bash hack/verify-recommender-metrics.sh`.
