# Balancer

> [!WARNING]
> **Balancer is deprecated and will be removed from this repository after the
> Kubernetes 1.38 release.** See
> [kubernetes/autoscaler#10499](https://github.com/kubernetes/autoscaler/issues/10499)
> for details. No new features or bug fixes will be accepted.

## Deprecation

As discussed in the SIG Autoscaling meeting and on the
[mailing list](https://groups.google.com/g/kubernetes-sig-autoscaling/c/EG3ZeiHfsLQ),
Balancer meets the inactivity criteria in the Kubernetes
[repository removal policy](https://github.com/kubernetes/community/blob/master/github-management/kubernetes-repositories.md#grounds-for-removal):

- there are no active maintainers and no replacements were found, and
- there have been no functional changes in more than a year.

The lazy-consensus period ended on 15 October 2026 with no objections.
Users should plan to migrate off Balancer before the Kubernetes 1.38 release.
